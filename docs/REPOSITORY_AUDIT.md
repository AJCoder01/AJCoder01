# GitHub portfolio audit — 9 September 2026

## Scope and method

Reviewed all seven repositories returned by the connected AJCoder01 account's owner inventory. The next pagination request returned no further repositories. All seven were public. Reviewed default-branch recursive file inventories (none truncated), every root README, selected implementation files, package scripts, and Rewind's progress record.

This is a portfolio and source-evidence audit, not an exhaustive code/security review. Builds, test suites, provider calls, and deployed demos were not run. Historical test results in existing documentation were not independently reverified. No credentials or external effects were used. Findings below describe the reviewed snapshot.

## Priorities

1. **Correct claims that a reviewer can disprove immediately.** ASIM's empty core files and TheAssembly's completed-recovery/backtesting language are the highest credibility risks.
2. **Make OneLessonAI easy to evaluate.** Its existing README, validation code, fixtures and evaluation docs provide the clearest end-to-end story. Reverify the existing checks and add CI.
3. **Show a precise Rewind slice.** Distinguish implemented code, fixture behavior, historical provider proofs and pending product proof. Avoid calling recovery complete.
4. **Add behavior tests to TOC Oracle.** Its deterministic algorithms make it a useful interview discussion project; cover empty strings, unbalanced strings, wrong order, alphabet changes and unsupported definitions.
5. **Keep the profile selective.** Suggested pin order: OneLessonAI, project-oracle, Rewind, TheAssembly. Pinning itself was not changed by this PR.
